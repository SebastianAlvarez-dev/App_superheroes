# Superheroes - Sebastian Alvarez

Practica de Android Basics with Compose: lista desplazable, tarjetas Material 3, fuente Cabin, temas claro y oscuro y animacion de entrada.

## Ejecutar
Abrir en Android Studio y ejecutar app en Android 7.0 (API 24) o superior.

Comprobar con: gradlew.bat testDebugUnitTest assembleDebug
